Quickstart

From sign-up to first request in 5 minutes.

概览

Prism 网关是个透明的算力路由：你给我们 API 请求，我们转发给上游（OpenAI / Anthropic / DeepSeek / Doubao / MiniMax），再把响应原样回给你。

  • 0% 加价 — 上游收我们多少，我们收你多少（精确到 µ¢）
  • 1.5% 充值手续费 — 充 $10,000 到账 $9,850（覆盖支付通道 / 商户费 / 链上 gas）
  • 22+ model 同一 API — 切换上游不用改代码
  • USDC 自动到账 — TRC20 / Solana / EVM 链上扫到自动入账

1. 鉴权

所有 API 调用需 Prism Key（不是上游 Key）。在 控制台 → API Keys 创建。

Key 格式：sk-prism-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx，41 字符。

两种传入方式：

Authorization: Bearer sk-prism-xxx
# 或
x-api-key: sk-prism-xxx     # Anthropic SDK 风格

2. OpenAI SDK 调用

把 base_url 换成 Prism，api_key 换成 Prism Key，其他全部不动。

Bash / curl

curl https://www.ai100trading.cn/suanli-api/v1/chat/completions \
  -H "Authorization: Bearer sk-prism-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "你好"}]
  }'

Python (openai SDK)

from openai import OpenAI

client = OpenAI(
    base_url="https://www.ai100trading.cn/suanli-api/v1",
    api_key="sk-prism-xxx",
)

resp = client.chat.completions.create(
    model="claude-haiku-4-5",      # 任选 22 个 model 之一
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
💡 同一个 OpenAI client 可以调用所有 Prism 暴露的模型，包括 claude-*、deepseek-*、doubao-*、 minimax-* ── 我们的网关会自动把 OpenAI 协议翻译成 Anthropic 协议。

3. Anthropic SDK / Claude Code 调用

Claude Code、anthropic-sdk-python 走 /v1/messages。

Claude Code

export ANTHROPIC_BASE_URL=https://www.ai100trading.cn/suanli-api
export ANTHROPIC_AUTH_TOKEN=sk-prism-xxx
claude  # 直接用即可

Python (anthropic SDK)

import anthropic

client = anthropic.Anthropic(
    base_url="https://www.ai100trading.cn/suanli-api",
    api_key="sk-prism-xxx",
)

msg = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}],
)
print(msg.content[0].text)

4. 流式响应

所有 model 支持流式（SSE）。OpenAI 风格：

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "讲个笑话"}],
    stream=True,
)
for chunk in resp:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

我们强制设 stream_options.include_usage=true，所以最后一帧会带完整的 token usage。这是计费依据，无法被关闭。

6. 错误码

错误响应统一为 OpenAI 风格 JSON：

{
  "error": {
    "message": "Invalid API key",
    "type": "authentication_error",
    "code": "invalid_api_key"
  }
}
HTTPtype什么时候发生
401authentication_errorPrism Key 无效或被 revoke
402insufficient_quota余额不足以承载这次请求的 max_tokens 上限
403permission_error账户未邮箱验证 / 被禁用 / 模型未授权
404invalid_request_errormodel_id 不存在或未启用
429rate_limit_errorRPM 超限（默认 60-1200，按 tier）
500api_error网关内部错
502api_error所有可用 channel 都失败 — 上游故障
503api_error该 model 没有可用 channel — 我们这边没接入

7. 计费精度

我们以 micro-cents（µ¢，1 USD = 100,000,000 µ¢）整数运算，杜绝浮点误差。

每条请求落 usage_logs 表一行，记录：

  • prompt_tokens / completion_tokens — 上游 usage 字段原值
  • cache_read_tokens — 命中 prompt cache 的部分（按 cache_read 价计费）
  • cache_write_tokens — Anthropic 写 cache 的部分（按 cache_write 价计费）
  • reasoning_tokens — OpenAI o-series 内部推理 token（按 output 价计费）

详细算法：docs/token-accounting.md

⚠️ 已知边界：Anthropic 1M-context 模型的 >200K token 部分上游收 2× 价，我们暂未分档； DeepSeek 错峰 5 折时段我们仍按全价收。详见 token-accounting.md §9。
