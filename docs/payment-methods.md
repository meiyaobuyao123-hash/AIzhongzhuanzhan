## 0. 通道总览

| 通道 | 推荐人群 | 手续费 | 到账 | 备注 |
|---|---|---|---|---|
| **支付宝** | 国内个人 | 万分之五 | 实时 | 通道成本 0.6% 我们自己吸收 |
| **微信支付** | 国内个人 | 万分之五 | 实时 | 通道成本 0.6% 我们自己吸收 |

| **USDT (EVM 系: ERC20 / BEP20 / Polygon / Arbitrum)** | 海外 / 加密用户 | 万分之五 | 视链而定 | ERC20 链上费高（$5-30），BSC/Polygon 便宜 |

## 1. USDT 收款地址

> 这两个地址是**对外公开的收款地址**（payment receiving address），客户充值时把 USDT 转过来即可。**不是私钥**，公开是设计如此。

### 1.1 Solana（USDT-SPL）

```
66p5tnV6Fd7x5QmRE6X772PMVmVUVgozRzATJ4Ns9iQn
```

- **网络**：Solana mainnet
- **代币标准**：SPL Token（USDT 在 Solana 上的标准）
- **链上转账费**：≈ $0.001（几乎零）
- **到账速度**：1-2 分钟（finalized）
- **适合**：技术圈用户、海外用户、追求低费用的用户
- **常见钱包**：Phantom / Solflare / Backpack / Trust Wallet

⚠️ **请务必选择 Solana 网络发送**。如果误用 ERC20 / TRC20 / BEP20 转到这个地址，**资金会丢失，无法找回**。

### 1.2 EVM 系（多链通用地址）

```
0xC862ff9Fd79D180950E546DBB8b108d5c9c38582
```

EVM（Ethereum Virtual Machine）系所有链共用同一个地址格式，但**链上代币需要区分**。我们支持以下网络：

| 网络 | USDT 合约 | 链上费 | 到账时间 | 推荐度 |
|---|---|---|---|---|
| **BSC（BEP20）** | `0x55d3...d955` | $0.10-0.30 | 30 秒 | ⭐⭐⭐⭐⭐ |
| **Polygon** | `0xc213...3e83` | $0.005-0.05 | 30 秒 | ⭐⭐⭐⭐⭐ |
| **Arbitrum** | `0xfd08...d9ab` | $0.05-0.50 | 1-2 分钟 | ⭐⭐⭐⭐ |
| **Ethereum（ERC20）** | `0xdac1...1ec7` | $5-30 | 1-3 分钟 | ⭐（贵）|

**优先推荐 BSC 或 Polygon**（费用低 + 到账快）。**不推荐 Ethereum 主网**（链上费几十美元，充小额会被吃没）。

⚠️ **同样务必选对网络**。从 ERC20 网络发送，到账只需要等 1-3 分钟；但 USDT 合约地址不同，必须保证你选的网络我们这边支持。

### 1.3 ❓ 暂不支持的网络

- **TRC20（Tron）**：当前没有 Tron 收款地址。这是 **国内圈子最常用的 USDT 网络**（链上费 ≈ $1，转账快），如果你的客户群偏国内加密用户，**强烈建议补一个 TRC20 地址**。Tron 地址格式以 `T` 开头，跟以上两个不通用。

如果要补 TRC20，给我一个 Tron 钱包地址（TronLink / imToken / OKX wallet 都能生成），我加进文档和首页。

## 2. 客户充值流程（USDT 例）

```
Step 1：客户在 Prism 控制台 → 充值 → 选 USDT
        ┌──────────────────────────────────────────────────┐
        │ 充值金额：[ 1000 USDT  ]                          │
        │ 选择网络：◉ Solana   ○ BSC   ○ Polygon            │
        │                                                  │
        │ 收款地址：66p5tnV6Fd7x5QmRE6X772PMVm...     [复制]│
        │ ⚠️ 请务必从 Solana 网络转账，转错网络资金丢失    │
        │                                                  │
        │ 系统会自动在链上监听该地址的转入。               │
        │ 转账完成后 1-3 分钟内余额自动更新。              │
        │                                                  │
        │ [我已转账] [取消]                                 │
        └──────────────────────────────────────────────────┘

Step 2：客户用 Phantom 钱包打开 → 转账 → 粘贴地址 → 确认
        链上 30-90 秒确认

Step 3：网关侧的链监听服务（v0.3 后）
        - 每 30 秒轮询：getSignaturesForAddress(收款地址)
        - 发现新交易 → 解析 amount + sender
        - 找到对应"待付款订单"（按 amount 匹配，或要求 memo）
        - amount × 0.9995 写入用户余额
        - 邮件通知客户"充值已到账"

Step 4：客户控制台余额刷新，可继续 API 调用
```

**v0.1 阶段简化**：
- 没有自动链上监听 —— 客户充值后**主动联系运营**（微信/邮件）截图
- 运营手动核对链上交易 → admin 后台手动加余额
- 1-3 个客户 / 天，运营成本可控
- 等月度链上充值笔数 > 30 时再上链监听服务（v0.3）


## 5. 安全说明

### 5.1 收款地址公开是安全的

- **支付宝/微信收款码** + **加密币收款地址** = "Public Address"，本质是「请把钱打给我」的标识
- 公开 ≠ 暴露私钥。私钥永远不上 GitHub、不放服务器、不发邮件
- 公开 ≠ 控制权丧失。只要私钥在你手里，资产 100% 在你控制下

### 5.2 收款地址被复制走怎么办

- 任何人复制走收款地址只能给你**汇款**，不能转走资产
- 唯一风险是被恶意转入"非法资金"，混淆资金来源（极罕见，且交易所会拒绝）
- 缓解：每个客户分配一个**虚拟收款子地址**（v0.3 后），减少混淆

### 5.3 私钥怎么管

- **不在这个仓库出现，永远不在任何代码仓库出现**
- 个人/小团队：硬件钱包（Ledger / Trezor）+ 助记词写在物理纸上、放保险柜
- 团队/公司：多签钱包（Safe）+ 2/3 授权
- 下次（v0.3+）做企业级方案时再细化

## 6. 运营 SOP（先手动跑起来）

每天定时（早上 / 下午 / 睡前）做一次：

```
1. 打开 Solscan / BscScan / Polygonscan，查我们收款地址有没有新转入
2. 打开支付宝商家版 / 微信商家版，看新到账
3. 对照"待审核充值"工单（客户自己截图发的）
4. 一一核对：金额、网络、时间戳、客户身份
5. admin 后台手动加余额（金额 × 0.9995）
6. 给客户发邮件 / 微信"充值 X 元已到账，扣手续费 0.05% 共 Y 元，余额 Z 元"
```

每天 < 30 分钟。月度笔数 > 30 时上自动化，参考第 2 节。
