  --exclude=.venv --exclude=__pycache__ --exclude=.pytest_cache \
  --exclude=prism.db --exclude=.env --exclude=prism_gateway.egg-info \
  -e 'sshpass -e ssh -o StrictHostKeyChecking=no' \

# 2. install + 跑 schema migration（幂等）

  pip install -e . --quiet && \

ssh ubuntu@... 'sudo systemctl restart prism'

## 已知警告（非阻塞）

- **BscScan API key 未配置** → 返回 `status=NOTOK`，监控视为"无新交易"继续轮询。
  生产前需要在 `/opt/prism/.env` 加 `PRISM_BSCSCAN_API_KEY=…`，否则 BSC 入账无法被检测。
  其他三链（Polygon/Arbitrum/Ethereum）同理。
- **Solana mainnet-beta 公共 RPC** 偶尔限速，监控在退避后恢复。生产建议换
  Helius / QuickNode 等 RPC，或配置专门的 endpoint。
